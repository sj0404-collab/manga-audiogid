# Манга Аудиогид

![Манга Аудиогид](cover.png)

Android-приложение, которое **читает мангу и вебтуны вслух**: распознаёт текст на странице
локально (PaddleOCR, кириллица) и озвучивает реплики системным TTS, подсвечивая облачка
на странице.

## Что умеет

- **Локальное OCR** без интернета: детекция облачек, нарезка слипшихся строк по «чернилам»,
  восстановление пробелов по частотному словарю (~47 000 словоформ).
- **Озвучка по репликам**: одно облачко — одна реплика, паузы между облачками, автолистание,
  скорость 0,25–2,0×, аудиожурнал главой в один ZIP.
- **Рамки на странице**: голубая — не прочитано, зелёная — прозвучало, серая — «молчание» (…),
  у каждой номер реплики. Рамки остаются на прокрученных страницах.
- **Без повторов**: уже озвученная реплика не читается второй раз, после перехода чтение
  продолжается с первой новой.
- **Отсев мусора**: номера глав, заставки, подписи команд перевода, водяные знаки и ссылки
  не читаются голосом; в журнале видно причину отсева.
- **Журнал работы** с координатами рамок, временем OCR и тем, что именно озвучено —
  по нему разбираются ошибки распознавания.

## Скачать

Последний APK — в разделе [Releases](../../releases) (две сборки: `arm64-v8a` и `armeabi-v7a`,
подпись постоянная, ставятся поверх друг друга).

## Сборка

```bash
# JDK 17 + Android SDK (platform 34, build-tools 34.0.0)
gradle :app:testDebugUnitTest
gradle -x lintVitalAnalyzeRelease -x lintVitalRelease :app:assembleRelease
```

APK появятся в `app/build/outputs/apk/release/`. В GitHub Actions то же самое делает
workflow `.github/workflows/build-apk.yml` (вкладка Actions → build-apk).

## Структура

```
app/src/main/java/lv/bibliogid/manga/
  ocr/            движки OCR (PaddleOCR onnx, ML Kit, облачные), конвейер страницы
  core/ocr/       группировка строк, склейка облачек, отсев декора, «молчание», текст страницы
  core/text/      нормализация, словарь, восстановление пробелов и регистра
  core/tts/       сценарий озвучки, ритм и паузы
  tts/            системный TTS, аудиожурнал
  ui/             читалка (лента и страницы), панель текста, журнал, настройки
```
